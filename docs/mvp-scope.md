# BSS Flow Academy — MVP V1 Scope

## Product

BSS Flow Academy
Build. Scale. Ship.

## Goal

Provide a simple registration and enrollment system for the first
web development cohort.

## MVP V1 learner journey

1. Visitor lands on the website.
2. Visitor learns about the programme.
3. Visitor registers.
4. Student either:
   - enters a valid Cohort 1 sponsored code, or
   - pays the standard ₦80,000 fee through Paystack.
5. The server verifies the applicable enrollment path.
6. An enrollment record is created.
7. Student receives access to the welcome page.
8. Student is directed to the Telegram community.

## Included

- Landing page
- Registration
- Cohort validation
- Cohort 1 sponsored enrollment
- ₦80,000 paid enrollment
- Paystack initialization
- Paystack verification
- Enrollment records
- Success/welcome page
- Telegram community link

## Not included in MVP V1

- Student dashboard
- Course progress tracking
- Online lessons
- Assignment system
- Certificates
- Admin dashboard
- Automated email system
- Telegram bot
- Video hosting
- LMS functionality

These may be introduced in later versions.
